> **代码架构**（分层、模块接口、数据流、迁移配方、测试）写在 `m4.5-ui-architecture.md`；本文件写需求、复用清单、功能行为、分批和风险。

## 需求与结论

### 主人的需求

- **界面整体放大**：现在偏小，Chrome 放大到 110% 刚好。
- **所有表格**  
  拖动表头边线改列宽，双击边线自动调整（同 Excel）；拖动表头调整列顺序；可以隐藏某一列。
- **渠道页分组**  
  默认按厂商分组、分组默认折叠、按分组排序；组内默认按优先级从高到低；厂商顺序可以调整。
- **布局保存**  
  调整结果要保存，跨设备同步，多用户时跟随用户；顶栏加"保存布局"按钮手动保存。
- **新增令牌**
    - 上游页和渠道向导的两个弹窗不一致：一个分组能下拉，一个不能。
    - 分组下拉在右侧弹出一个很大的列表，每项太高。
    - 要求：在下方弹出，分组名靠左；渠道倍率、渠道标价倍率（= 渠道倍率 × 上游汇率）靠右并分别上下对齐；右边放不下时这两项整体换到第二行。
- **按模型看统计**  
  首字延迟、吐字速度与模型相关；页面上选模型后，各渠道显示该模型的数据，成本和缓存率也跟着变。
- **代码复用**  
  尽量复用模块，不要每个地方各写一份；表格、弹窗以及其它地方一起评估。
- **分工**  
  计划里要有充分的代码架构设计；<u>执行只交给 sonnet</u>。

### 讨论定下的结论

- **放大**
    - 基准字号设为 110%，所有尺寸跟着它走；不提供调节选项。
    - 写死的像素值分四类处理：样式改 rem、代码里的尺寸写 rem、保存的尺寸用 rem 或比例、按元素大小算位置的改用自动定位（架构文件"尺寸"）。
- **复用范围**  
  做第一档（需求直接要用的）和第二档（重复多、收益高的）；第三档以后再说。
- **分批**  
  五批，每批编译通过、主人在浏览器里试过，再进入下一批。<u>迁移批只换写法，不改功能</u>。
- **渠道页**
    - 默认按厂商分组，所有分组默认折叠，折叠状态不保存。
    - 厂商分组的顺序 = 设置页的厂商顺序（AutoGroups 顺序），渠道页里不能拖；"无厂商"永远最后。
    - 代码里<u>不内置</u>任何厂商顺序，主人在设置页拖一次即可。
    - 按上游、按标签分组时可以拖动分组顺序，跟布局一起保存。
    - 组内默认按优先级降序 → 权重降序 → 名称；点表头只在组内排序。
- **设置页**  
  厂商顺序改为拖动调整（与表格拖动共用组件），拖完立即保存并记审计，和现在的上移下移一样。
- **布局保存**
    - 顶栏"保存布局"按钮一次保存全部；有未保存的改动时按钮上有提示；可以恢复上次保存，也可以恢复默认。没保存就刷新，改动会丢。
    - 存在 nam.db 现有的设置表，按用户 ID 一条；读写布局不记审计。
    - <u>保存</u>：列宽、列顺序、隐藏的列、排序、分组方式、分组顺序（上游 / 标签）、下栏高度。
    - <u>不保存</u>：筛选、搜索、折叠状态、选中的模型（模型写进网址 `?model=`）。
- **新增令牌**：只有一个弹窗，自己取分组；分组用可搜索的下拉。
- **按模型统计**
    - 渠道页工具栏加模型选择框（可搜索）。选中后仍显示全部渠道，没有这个模型的渠道，统计列和成本列留空。
    - 选了模型：成功率、首字延迟、吐字速度、缓存命中率、实测成本价、标准负载成本价、价格档都按这个模型算；单次成本、上游渠道成本价也按这个模型算，有模型级折扣就用它。
    - 没选模型：首字延迟、吐字速度留空（提示"选择模型后显示"）；其余显示全部模型的汇总。

## 功能行为

> 这里写主人看到的效果；实现方式见架构文件"页面与后端"。

### 渠道页：分组、排序、折叠

- **默认**：按厂商分组，全部折叠；组内按优先级降序 → 权重降序 → 名称升序。
- **组的顺序**
    - **按厂商**：设置页的厂商顺序；渠道上的厂商不在厂商列表里时，按名称排在后面；"无厂商"最后。不能拖动。
    - **按上游**、**按标签**：按保存的顺序；新出现的组按名称排在后面；"未托管" / "无标签"最后。可以拖动组标题调整，跟布局一起保存。
    - 按上游分组时以上游 ID 识别，上游改名后顺序不丢。
- **折叠**：切换分组方式时重新全部折叠；搜索框有内容时全部展开。
- **排序**：点表头 升序 → 降序 → 回到默认排序，只在组内排序；空值永远排在最后。
- **组标题行摘要**：渠道数、启用数、平均成功率、成本；选了模型时用这个模型的统计。

### 渠道页：按模型显示统计

- **选择模型**：工具栏"统计时长"旁边的模型选择框，可以输入筛选，每项显示有几个渠道包含它，按厂商分组；可以清除。
- **选中的模型写进网址**（`?model=`），刷新和分享链接都保留。
- **选了模型**
    - 仍然显示全部渠道。
    - 成功率、首字延迟、吐字速度、缓存命中率、实测成本价、标准负载成本价、价格档：按这个模型的数据。
    - 单次成本、上游渠道成本价：按这个模型计算，模型有单独折扣时用单独折扣。
    - 不含这个模型的渠道：统计列和成本列显示 `—`。
    - "最新"档每个渠道只看最近 100 条日志，按模型过滤后样本可能很少，质量档会显示"样本不足"。
- **没选模型**：首字延迟、吐字速度显示 `—`，表头和单元格提示"选择模型后显示"；其余列显示全部模型的汇总（和现在一样）。
- **下栏模型明细**：不变，高亮选中的模型。

### 表格通用操作

- **列宽**：拖动表头右边线；双击边线自动调整。
- **列顺序**：按住表头拖动。
- **表头右键菜单**：隐藏此列、显示列、自动调整此列、自动调整全部列、恢复本表默认布局。工具栏右侧的"列"按钮打开同一份菜单。
- **保存**：所有表格的列宽、列顺序、隐藏列、排序都记在布局里，按"保存布局"后同步到服务器。
- **服务端分页的表**（审计、模型与价格）：可以改列宽、列顺序、隐藏列，但点表头不排序，因为只能排当前这一页。

### 新增令牌、设置页、顶栏

- **新增令牌**
    - 上游页和渠道向导打开的是同一个弹窗，都能下拉选择分组。
    - 分组下拉在输入框下方弹出，每项和表格行一样高；分组名靠左，"渠道倍率""渠道标价倍率"两列靠右并上下对齐；弹层太窄时两列整体换到第二行。
    - 可以输入列表里没有的分组名；上游还没同步过分组时，列表里有"同步分组"按钮。
    - 向导"选令牌"一步的表格多一列"渠道标价倍率"。
    - 术语：渠道倍率 = 上游的分组倍率；渠道标价倍率 = 渠道倍率 × 上游货币汇率。界面其它地方的"分组倍率"本次不改名。
- **设置页厂商**：拖动行调整顺序，立即保存并记审计；渠道页按厂商分组的顺序随之改变。上移下移按钮删除。
- **顶栏**："保存布局"按钮，有未保存的改动时带小圆点；旁边的下拉菜单里有"恢复上次保存""恢复默认布局"。恢复默认后仍要点保存才会写到服务器。

## 分批实施

> **每批流程**：sonnet 按架构文件执行 → 我核对产物 → `npm run build`（含 `check.mjs`）+ `npm test`，涉及后端时再跑 `go vet ./...`、`go test ./...` → 主人在浏览器里试 → 进入下一批。  
> **分工**：实现交给 fixer（模型 `newapi/claude-sonnet-5-5`，mammotion-claude 线路会拒绝子代理请求）；视觉部分交给 designer（同样用 `newapi/claude-sonnet-5-5`）；架构由我负责，执行中遇到架构文件没写到的取舍，由我决定后补进架构文件。  
> **并行**：同一批里并行的分支<u>写入范围不重叠</u>。

## 风险与约定

### 风险

- **改动面大**
    - 五批几乎会碰到每个页面（约 70 个文件），而前端此前还没在浏览器里完整点过一遍。
    - 对策：迁移批只换写法；每批收尾打开对应的 `check.mjs` 规则；每批主人试用；出了问题能定位到具体哪一批。
- **表格核心由 sonnet 实现**
    - 列宽、列顺序、分组拖动、框选、编辑、右键菜单都在同一个组件里，交互容易互相干扰。
    - 对策：架构文件把数据流、文件划分和每个纯函数的规则写死；纯函数先写测试；`GridDemo` 页逐项可试；完成后 gpt-6-astra 审查代码。
- **拖动和框选冲突**  
  拖列只在表头生效，框选只在表体生效；移动超过 4 像素才开始拖动，避免误触；改宽手柄阻止拖动。
- **布局对账**  
  以后加列、删列时，已保存的布局不能出错。规则集中在 `components/table/layout.ts`，有单元测试，`GridDemo` 里有演示。
- **多设备覆盖**：后保存的覆盖先保存的，不做合并。
- **新依赖**  
  `@dnd-kit/core`、`@dnd-kit/sortable`、`@dnd-kit/utilities`、`@dnd-kit/modifiers`、`@radix-ui/react-context-menu`、开发依赖 `vitest`；版本像现有 `package.json` 一样写死；下载走代理 `127.0.0.1:7890`。
- **独立模式只有一份布局**：用户 ID 来自环境变量，这是现状，本次不改。
