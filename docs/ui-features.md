# nam 界面功能说明

本文根据草稿前端 `temp/ui-src` 整理（该草稿不提交 git；当前原型以 `docs/ui/mockup.html` 为准），只描述页面结构、操作和用户逻辑，不涉及样式和代码实现。
草稿里有一部分内容已经被 `docs/requirements.md` 第 10 轮修订（如成本系数 f、"模型数"列、统计时长），本文已按需求文档改正。这些地方标注了"（按需求修订）"。

## 0. 通用约定

- 写入分两类：
  - 只写 nam 数据库：上游、通知、别名、覆盖价等。
  - 写 NewAPI：渠道、价格、部分设置。写 NewAPI 的操作都要先预览差异或二次确认。每次写入都会记录写入前的值，可以回滚。
- 渠道的修改先进入"草稿"，统一"应用变更"后才写入 NewAPI。
- 界面上的参数一律用中文名，例如价格倍率（k）、充值汇率（r）、名义成本系数（k×r）、站点汇率（S）。
- 浮层有三种：弹窗、右侧抽屉、确认框。Esc 可以关闭。
- 操作结果用 Toast 提示。

## 1. 全局框架

- 运行方式（按需求 A1–A8 修订）：
  - 嵌入模式（默认）：页面挂在 NewAPI 同域的 `/nam/` 下，直接使用 NewAPI 的登录会话，只有 root 能进入。
    - 未登录时跳转到 NewAPI 登录页；已登录但不是 root 时显示"无权限"页。
    - NewAPI 侧边栏有一个只对 root 显示的入口。
  - 独立模式：使用下面的登录页。
- 登录页（只在独立模式出现）：单管理员，只需要输入密码。
  - 密码错误时提示已失败的次数，连续失败 5 次锁定 60 秒。
  - 会话 7 天有效。
- 左侧导航分三组：
  - 监控：总览、统计。
  - 配置：上游、渠道、模型与价格、路由策略（预留）。
  - 运维：写入历史与审计、通知、设置。
  - 导航项旁显示数量徽标，例如上游数、渠道数、待处理的模型数。
- 顶栏：
  - 全局搜索（Ctrl+K）：可以搜页面、上游、渠道、模型。点击搜索结果会跳到对应页面，或打开对应的详情。
  - NewAPI 连接状态：点击后弹窗显示运行模式（嵌入 / 独立）、版本、访问身份、最近一次请求。独立模式下还显示地址，并可跳到设置页。
  - 待应用草稿 N：点击打开"应用变更"弹窗。
  - 用户菜单：我的写入记录、返回 NewAPI（嵌入模式）；修改密码、退出登录（独立模式）。

## 2. 总览

- 告警卡片，点击后跳到对应页面并带上筛选条件：
  - 低余额上游
  - 被 NewAPI 自动禁用的渠道
  - 价格变动待确认
  - 渠道漂移（在 NewAPI 侧被改过）
  - 上游同步失败
- 今日指标：可以切换"今日 / 近 24h"。指标有请求数、成功率、成本、收入、毛利，并和昨日同时段对比。
- 余额汇总：
  - 列出各上游的余额（美元）、充值汇率和折合人民币，按余额从低到高排序，显示合计。
  - 点击某行打开该上游的详情抽屉。
- 后台任务表：
  - 任务有余额同步、倍率同步、价格库同步、公告检查、日志拉取、定价计算、一致性检查。
  - 每个任务显示执行间隔、上次运行时间、耗时和结果。
  - 每行有"立即运行"按钮。任务串行执行，点击后加入队列。
- 最近 5 条写入 NewAPI 的记录，带"全部写入历史"的跳转链接。

## 3. 上游

### 3.1 列表
- 工具栏：
  - 新增上游
  - 批量同步：勾选上游后可用
  - 按类型、标签筛选，按名称或地址搜索
  - 从总览跳转过来时显示筛选来源，可以清除
- 表格列：勾选框、名称和地址、类型、标签、充值汇率、凭证状态、余额（美元）、折合人民币（低余额时标色）、令牌数、渠道数、最近同步时间、错误信息、单行"立即同步"按钮。
- 点击某行打开详情抽屉。没有数据时显示空状态和"清除筛选"按钮。

### 3.2 新增上游向导（弹窗，5 步）
1. 填写名称和站点地址（根地址），校验地址格式。
2. 自动识别类型，显示识别依据。可以手动改选类型：newapi、sk-key、sub2api、onehub、official、generic。
3. 选择凭证方式并填写：
   - Access Token + 用户 ID
   - 账号 + 密码
   - 仅 sk-key（这种方式没有令牌列表和分组倍率，价格倍率需要手填）
4. 连通性测试：逐项显示站点可达、凭证有效、令牌列表、分组倍率、公告的结果和耗时。可以重新测试；失败时可以返回修改。
5. 填写充值汇率（附换算示例）、标签、备注。勾选保存后是否立即同步令牌、分组倍率和余额。最后点"保存并同步令牌"。

### 3.3 上游详情抽屉（多个标签页）
- 概览：
  - 显示余额、折合人民币、渠道数/令牌数、7 天成本。
  - 最近同步失败时显示失败提示。
  - 可编辑名称、地址、类型、标签、备注、充值汇率（提示：修改后会影响该上游所有渠道的成本）。
  - 凭证状态，带"更换凭证"和"测试连通性"按钮。
- 分组倍率：显示上游的分组名、分组倍率、使用该分组的渠道数、更新时间。有"立即同步倍率"按钮。
- 上游模型价格（按需求修订）：
  - 同步上游的逐模型原始价格（输入、输出、缓存读、缓存写，或按次价），并换算到各分组。
  - 与渠道价格倍率偏差超过 5% 的模型会被标出，可以设为该模型的单独倍率。
- 令牌：
  - 列出令牌名、分组、额度、状态、是否已建渠道。
  - 未建渠道的令牌有"建渠道"按钮，点击后跳到渠道页的批量创建，并预选该上游。
  - 可以手动录入令牌；newapi/onehub 类上游还可以"在上游新建令牌"（弹窗填写令牌名、分组、额度）。
- 公告：显示检测时间、是否有变化、内容摘要。
- 适配器配置：只有 generic 类型需要配置。
  - 字段有余额请求地址、请求方法、请求头、JSON 路径、换算系数、公告页面地址。
  - 有"测试"按钮，显示解析出的余额。
  - 其它类型只读展示。
- 同步日志：显示时间、任务、结果、耗时、说明。
- 底部按钮：
  - 删除上游：确认后，把该上游所有渠道的删除加入草稿。
  - 立即同步
  - 保存

## 4. 渠道（核心页）

### 4.1 页面结构
- 页头按钮：
  - 草稿计数、放弃草稿（需要确认）
  - 应用变更
  - 批量创建
- 工具栏：
  - 分组方式：按上游、按厂商、按标签、不分组。
  - 筛选：状态（启用、手动禁用、自动禁用）、上游、厂商、标签、同步状态（已同步、草稿、漂移、错误）。
  - 搜索：名称、令牌、模型。
  - 统计时长（按需求修订）：最新（每个渠道 24 小时内最近 100 条请求）、3 天、7 天，默认"最新"。
  - 有勾选行时显示"批量启用 / 批量禁用"。
  - "列"按钮：选择显示哪些列。
- 主体分为上下两张表，中间的分隔条可以拖动调整高度：
  - 上表：渠道表格。
  - 下表：当前选中渠道的模型明细。

### 4.2 渠道表格
- 组标题行：显示组名、渠道数、平均成功率、成本合计。点击可以折叠或展开。
- 列（✎ 表示可编辑）：
  - 勾选框
  - 状态
  - 名称 ✎（必须唯一）
  - 上游
  - 令牌（分组）
  - 厂商
  - 模型（按需求修订）：显示"x 个模型"，悬停显示完整列表；支持复制粘贴，内容为逗号分隔的模型名；双击打开模型编辑器，可以追加或移除模型。
  - 价格倍率 k ✎：标注来源是自动还是手动。
  - 充值汇率 r
  - 名义成本系数 k×r
  - 优先级 ✎
  - 权重 ✎
  - 标签 ✎
  - 成功率
  - 首字延迟
  - 吐字速度
  - 缓存命中率
  - 成本系数（按需求修订）：
    - 实测成本系数：考虑缓存后的实际成本。
    - 标准负载成本系数：可以在渠道之间横向比较。
    - 成本按颜色梯度显示，并给出价格/质量评级。
  - 成本（元）
  - 同步状态：已同步、草稿、草稿·新建、草稿·删除、漂移（点击打开对比）、错误。
- 改动过的单元格要高亮，漂移的字段也要高亮。被禁用的行显示为弱化样式。

### 4.3 表格交互（参考 oc-modal-configurator）
- 编辑：
  - 双击、Enter 或 F2 进入编辑；Enter 保存，Esc 取消。
  - 输入要校验：k 必须大于 0；优先级和权重必须是整数，权重不小于 0；名称不能为空且不能重复。
  - 点击只读列时，提示该列为什么不能编辑。
- 选区：
  - 拖动框选，Shift+点击扩展选区，方向键移动焦点（Shift+方向键扩展选区）。
  - 底部提示条显示选区大小和快捷键说明。
- 复制粘贴：
  - Ctrl+C 只能复制单行，可以包含多列。只有状态、k、优先级、权重、标签、模型这几列能被复制，其它列会被跳过并提示。
  - 复制后，框选目标行，按 Ctrl+V 粘贴。修改进入草稿，并提示改了多少格。
  - Esc 取消复制。
- 右键菜单：
  - 启用 / 禁用（进入草稿）
  - 测试渠道：确认后调用 NewAPI 的测试接口，提示会产生少量费用。
  - 在 NewAPI 中打开
  - 复制为新渠道（进入草稿）
  - 查看漂移差异
  - 删除：确认后进入草稿。

### 4.4 模型明细（下表）
- 表头显示渠道名、厂商、渠道的 k 和 r、测试模型。
- 按钮：
  - 添加模型
  - 从上游 /v1/models 对比：提示上游有哪些新增模型。
- 列：
  - 模型名
  - 上游模型名（映射）✎
  - 官方价：输入、输出、缓存读、缓存写，或按次价
  - 模型级 k 覆盖 ✎：留空表示沿用渠道 k。和上游价格偏离时显示"偏离"标记。
  - 成本（元/1M，输入/输出）
  - 请求数、成功率、首字延迟、吐字速度
- 修改映射或 k 覆盖都会进入草稿。

### 4.5 批量创建向导（弹窗，5 步）
1. 选上游：显示类型、r、令牌数、已建渠道数。
2. 选令牌：可多选，有"全选未建渠道的"按钮。显示令牌的分组、分组倍率、额度、状态，以及是否已有渠道。
3. 选模型：
   - 可以用厂商模板一键勾选，也可以按厂商分组逐个勾选。缺价的模型会标出。
   - 可以从上游 /v1/models 拉取模型列表。
   - 生成时按厂商拆分，一个渠道只放一个厂商的模型。
4. 命名与默认值：
   - 命名规则 `nam-<上游>-<令牌>-<厂商>`。
   - 填写默认优先级、权重、标签。
   - 测试模型：默认自动选渠道内最便宜的模型，也可以手动指定。
   - 说明 k 的来源：自动推算或手动填写。
5. 预览：列出将生成的渠道，包括名称、令牌、厂商、模型、推算出的 k、优先级、权重、测试模型。重名的会被标出。点击"加入草稿"后跳到渠道页。

- 从上游详情的"建渠道"进入时，直接从第 2 步开始。

### 4.6 应用变更（弹窗）
- 差异预览：
  - 按渠道列出字段、旧值 → 新值，以及对应的 NewAPI 请求（新建、修改、删除）。
  - 只影响 nam 的字段（如 k）会注明"不写 NewAPI"。
  - 可以展开查看请求体。
- 点击"确认并执行"后，串行逐条执行，显示进度条和每条的结果。
- 失败的项保留为草稿，可以单独重试。
- 完成后汇总成功数和失败数。

### 4.7 漂移对比（弹窗）
- 逐字段对比 nam 上次应用的值和 NewAPI 当前值，标出不同的字段。只比较 nam 管理的字段：模型、优先级、权重、标签、状态、测试模型、base_url（按需求 A6 修订）。
- 操作：
  - 稍后处理
  - 采纳 NewAPI 值：只更新 nam。
  - 以 nam 为准覆盖：需要二次确认，然后写 NewAPI。

## 5. 模型与价格（按需求修订）

草稿中"按 7 天加权成本 f 自动定价"的方案已被替代，改为按厂商设置售价倍率。

- 厂商定价区：
  - 每个厂商设置一个售价倍率 m。
  - 定价模式有两种：固定，或跟随参考成本（取该厂商各渠道的实测成本系数）。
  - 变化超过阈值时进入"待确认"。
  - 显示各用户分组下的售价示例。
- 页头按钮：
  - 同步价格库：LiteLLM / models.dev，只同步站内存在的模型。
  - 立即计算：只计算，不写入。
  - 预览写入
- 筛选：
  - 状态：全部、正常、待确认、缺价、按次计费，各显示数量。
  - 厂商
  - 搜索：模型名或别名
- 排序：
  - 默认把未设价格的模型排在前面。
  - 搜索时，前缀命中排在中间命中前面；同一命中类型内再按"是否设价"排序，最后按名称排序。
- 模型表列：
  - 模型（厂商、别名）
  - 官方价：输入、输出、缓存读、缓存写，或按次价
  - 价格来源：价格库 / 手动覆盖
  - 使用该模型的渠道数
  - 将写入 NewAPI 的倍率
  - 各用户分组的售价
  - 上次写入时间
  - 状态
- 行操作：
  - 待确认的模型有"确认"按钮：确认框说明变化原因，确认后写入。
  - 更多菜单：查看计算明细（抽屉，列出参与计算的渠道和公式展开）、覆盖官方价（弹窗，见下）、设置别名（弹窗，见下）。
  - 双击行打开计算明细。
- 覆盖官方价（弹窗）：
  - 选择计费方式：按 token 或按次。
  - 填写各项价格和备注。
  - 有"清除覆盖"按钮。只写 nam。
- 设置别名（弹窗）：每行填一个上游模型名，映射到官方模型名。只写 nam。
- 预览写入（弹窗）：
  - 按 option（ModelRatio、CompletionRatio、CacheRatio、ModelPrice 等）列出变化条数和示例。
  - 跳过待确认和缺价的模型。
  - 流程：写入前校验，写入后读回核对，并记录历史，可以回滚。

## 6. 统计

- 时间范围：24 小时、7 天、30 天、自定义日期。
- 维度：渠道、模型、上游。
- 图表：
  - 请求量与成功率
  - 首字延迟与吐字速度（p50/p95）
  - 成本 vs 收入
  - 价格-质量散点图（按需求修订）
- 排行榜：
  - 列：名称、请求数、成功率、失败数、首字延迟 p50/p95、吐字速度、成本、收入、毛利率。
  - 点击表头排序，可以导出 CSV。
  - 渠道维度下，点击某行打开渠道详情抽屉。
- 渠道详情抽屉：
  - 显示关键指标和逐小时图表。
  - 逐小时表：成功数、失败数、失败类别、首字延迟、吐字速度、缓存率、成本。
  - 有"在渠道页打开"按钮。
- 错误类别分布：429、5xx、超时、401、余额不足、其他。
- 本页只读。

## 7. 路由策略（预留，算法待讨论）

- 策略选择：
  - 手动：在渠道页直接填优先级和权重。
  - 按成本分层
  - 质量加权：不可选，作为预留。
- 分层参数：层边界、各层优先级、权重规则。目前只做展示。
- 分层预览：
  - 选择一个模型，查看各层的渠道，包括成本系数、成功率、当前和建议的优先级/权重。
  - "生成建议 → 加入草稿"：只生成草稿，仍需在渠道页应用。

## 8. 写入历史与审计

- 筛选：类型（渠道、价格、设置）、触发方式（自动、手动）、结果（成功、失败、已跳过）、日期范围、搜索。
- 列表列：时间、类型、对象、变更摘要、触发方式、结果、操作人。
- 点击某行展开，显示完整差异和原始请求/响应。
- 回滚：
  - 渠道类记录：生成反向草稿，再到渠道页应用。
  - 价格、设置类记录：确认后直接回滚，并读回核对。回滚本身也会记录一条审计。

## 9. 通知

- 通道卡片，每张卡片有启用开关、"发送测试"和"保存"按钮：
  - Telegram：Bot Token、Chat ID、API Base。
  - Webhook：URL、消息模板。
  - 邮件：SMTP 地址和端口、账号、密码、收件人。
- 规则表：
  - 事件类型有低余额、渠道被禁用、价格变动、公告变化、同步失败、写入失败、渠道漂移。
  - 每条规则可以设置阈值、通道（多选）、冷静期、是否启用，还有"模拟触发"按钮。
  - 低余额规则支持按上游单独覆盖阈值（显示为子行，可以删除）。
- 事件记录：时间、事件、内容、各通道的投递结果、状态（已发送、冷静期内已去重、部分失败）。

## 10. 设置

左侧有分区目录，点击可跳到对应分区。标注"写 NewAPI"的项保存前需要确认。

- NewAPI 连接：
  - 嵌入模式：只读显示运行模式、NewAPI 版本、是否检测到补丁。
  - 独立模式：地址、root 访问令牌、用户 ID。"测试连接"会显示版本、是否检测到补丁，并校验该用户是 root（角色 100），不是 root 时提示错误。
- 高危操作（查看凭证明文、修改站点汇率 S）：嵌入模式下需要先通过 NewAPI 的二次验证（2FA 或 Passkey）。
- 站点汇率 S：
  - 显示当前值，可以输入新值，然后点"预览影响"。
  - 弹窗说明影响：各倍率整体缩放、用户看到的人民币价格不变、用户已有余额会被重新估值。
  - 必须勾选"我已了解"，再经过二次确认才能写入。
- 用户分组加价：
  - 表格列：分组名、加价倍率、说明。可以增删分组，self 分组不能删除。
  - 保存时需要确认，然后写 NewAPI。
- 定价参数：
  - 变化保护阈值
  - 冷启动策略
  - 自动写入开关：关闭后只计算，不自动写入。
- 调度间隔：每个后台任务的执行间隔，单位可选分钟、小时、天。
- 日志保留：
  - NewAPI 原始日志保留天数：由 nam 负责清理，会写 NewAPI。
  - nam 聚合数据保留天数。
- NewAPI 自动禁用/恢复：
  - 自动禁用开关、自动恢复开关、全量定时测试开关（建议保持关闭）、测试间隔。
  - 修改开关需要确认，然后写 NewAPI。
- 备份：立即备份、最近备份列表、下载。
- 修改管理员密码（只在独立模式出现）：输入当前密码、新密码和确认密码。修改后，其它会话全部失效。
