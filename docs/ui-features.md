# nam 界面功能说明

本文是**重新实现界面时的功能清单**：页面、表格列、按钮、弹窗和用户逻辑。<u>视觉设计不在本文规定</u>，由新界面自行设计（表格要信息密集，能支撑大表格编辑）。
`docs/ui/mockup.html`、`docs/ui/sitemap.svg` 和 `temp/ui-src` 都**已过时**，不作为实现依据，也不要参考它们的代码和样式。

## 0. 通用约定

- 写入分两类：
  - 只写 nam 数据库：上游、通知、别名、覆盖价等。
  - 写 NewAPI：渠道、价格、部分设置。写 NewAPI 的操作都要先预览差异或二次确认。每次写入都会记录写入前的值，可以回滚。
- 渠道的修改先进入"草稿"，统一"应用变更"后才写入 NewAPI。
- 界面上的参数一律用中文名，例如原厂价、上游分组倍率、上游货币汇率、美元参考汇率、上游渠道售价、售价、站点汇率。界面上不出现单个字母的参数名。
- 成本和倍率类的列要写清单位，表头悬停给出公式和例子（定义见 `requirements.md` 的"参数说明"）。
    - 上游分组倍率显示小数，如 `0.35`。
    - 上游货币汇率带单位 `元/$`。
    - 上游渠道售价、实际负载成本、实际计费倍率、标准负载成本、参考成本、售价是<u>原厂价的倍数</u>，显示为百分比，如 `2.4%`。
    - 单次成本、成本仍以元为单位。
- 浮层有三种：弹窗、右侧抽屉、确认框。Esc 可以关闭。
- 操作结果用 Toast 提示。

## 1. 全局框架

- 运行方式：
  - 嵌入模式（默认）：页面挂在 NewAPI 同域的 `/nam/` 下，直接使用 NewAPI 的登录会话，只有 root 能进入。
    - 未登录时跳转到 NewAPI 登录页；已登录但不是 root 时显示"无权限"页。
    - NewAPI 侧边栏有一个只对 root 显示的入口。
  - 独立模式：使用下面的登录页。
- 登录页（只在独立模式出现）：单管理员，只需要输入密码。
  - 密码错误时提示已失败的次数，连续失败 5 次锁定 60 秒。
  - 会话 7 天有效。
- 左侧导航分三组：
  - 监控：总览、统计。
  - 配置：上游、渠道、模型与价格、路由策略（预留）。
  - 运维：写入历史与审计、通知、设置。
  - 导航项旁显示数量徽标，例如上游数、渠道数、待处理的模型数。
- 顶栏：
  - 全局搜索（Ctrl+K）：可以搜页面、上游、渠道、模型。点击搜索结果会跳到对应页面，或打开对应的详情。
  - NewAPI 连接状态：点击后弹窗显示运行模式（嵌入 / 独立）、版本、访问身份、最近一次请求。独立模式下还显示地址，并可跳到设置页。
  - 待应用草稿 N：点击打开"应用变更"弹窗。
  - 保存布局：一个小图标按钮加一个下拉箭头，见下方"布局保存"。
  - 用户菜单：我的写入记录、返回 NewAPI（嵌入模式）；修改密码、退出登录（独立模式）。
- 界面整体按浏览器默认字号的 110% 显示。

### 表格通用操作

全站表格（渠道、上游、令牌、价格、审计、统计排行榜、厂商等）使用统一组件，交互完全一致：

- **列宽**：拖动表头右边缘调整；双击右边缘按内容自动自适应。
- **列顺序**：按住表头左右拖动（勾选框等固定列除外）。
- **显示列**：点击右上角"列"按钮，按需勾选。
- **排序**：点击表头切换：升序 → 降序 → 恢复默认。
- **分组**：组标题行支持点击折叠或展开；<u>发起搜索时自动全部展开</u>。
- **框选与批量复制**：仅可编辑表格（如渠道页）支持，规则见渠道表格。
- **只读列**：点击单元格时提示不可编辑的原因。
- **下拉选择**：长列表下拉均支持**输入文本搜索**。

### 布局保存

- **保存范围**：
    - 各表格的列宽、列顺序与隐藏列。
    - 上下分栏的高度比例。
    - 渠道页的分组方式，以及按上游 / 标签分组时的拖拽顺序。
- **保存机制**：
    - **按用户保存在服务器**：跨浏览器、跨设备打开保持一致。
    - <u>不会自动保存</u>：调整后顶栏保存图标出现"未保存"提示点，手动点击才会写入服务器。
    - 保存中若继续调整，保存完成后仍会保持"未保存"状态。
- **按钮状态说明**：
    - **转圈**：正在加载或正在保存。
    - **红色警告**：加载失败，点击可重试。
    - **灰色勾号**：当前为已保存状态。
    - **保存图标加小圆点**：存在未保存的本地修改。
    - 鼠标悬停均有完整文字说明。
- **下拉菜单**：
    - **恢复上次保存**：丢弃未保存的修改，拉回线上配置。
    - **恢复默认布局**：重置为初始布局（重置后需再次点击保存才会同步到服务器）。
- **状态限制与例外**：
    - **未加载完成前**：禁用列宽、列顺序与分栏调整，悬停提示"布局未加载"。
    - <u>不随布局保存的项</u>：统计时长、模型明细折叠状态（保存在浏览器本地）、当前选中的模型（记在 URL 网址参数中）。

## 2. 总览

- 告警卡片，点击后跳到对应页面并带上筛选条件：
  - 低余额上游
  - 被 NewAPI 自动禁用的渠道
  - 价格变动待确认
  - 渠道漂移（在 NewAPI 侧被改过）
  - 上游同步失败
- 今日指标：可以切换"今日 / 近 24h"。指标有请求数、成功率、成本、收入、毛利，并和昨日同时段对比。
- 余额汇总：
  - 列出各上游的余额（美元）、上游货币汇率和折合人民币，按余额从低到高排序，显示合计。
  - 点击某行打开该上游的详情抽屉。
- 后台任务表：
  - 任务有余额同步、倍率同步、价格库同步、公告检查、日志拉取、定价计算、一致性检查。
  - 每个任务显示执行间隔、上次运行时间、耗时和结果。
  - 每行有"立即运行"按钮。任务串行执行，点击后加入队列。
- 最近 5 条写入 NewAPI 的记录，带"全部写入历史"的跳转链接。

## 3. 上游

### 3.1 列表
- 工具栏：
  - 新增上游
  - 批量同步：勾选上游后可用
  - 按类型、标签筛选，按名称或地址搜索
  - 从总览跳转过来时显示筛选来源，可以清除
- 表格列：勾选框、名称和地址、类型、标签、上游货币汇率（元/$）、凭证状态、余额（美元）、折合人民币（低余额时标色）、令牌数、渠道数、最近同步时间、错误信息、单行"立即同步"按钮。
    - 凭证状态：会话 Cookie 显示"Cookie 约 N 天后过期"，≤3 天黄色、已过期红色；sub2api 显示"凭证更新于 x 前"。
    - 错误信息含"已失效"时标红，并出现"更换凭证"按钮。
- 点击某行打开详情抽屉。没有数据时显示空状态和"清除筛选"按钮。

### 3.2 新增上游向导（弹窗，5 步）
1. 填写名称和站点地址（根地址），校验地址格式。
2. 自动识别类型，显示识别依据。可以手动改选类型：newapi、sk-key、sub2api、onehub、official、generic。
3. 选择凭证方式并填写：
   - Access Token + 用户 ID
   - 账号 + 密码
   - 仅 sk-key（这种方式没有令牌列表和分组倍率，上游分组倍率需要手填）
   - 会话 Cookie + 用户 ID（NewAPI / OneHub）：多行 Cookies 输入框，只填 `session` 的值或整串 Cookie 都行；NewAPI 必填用户 ID，OneHub 可选。旁边是可折叠的"怎么获取"和复制按钮（浏览器登录后按 F12 → 应用 → Cookie 复制 `session` 的值；用户 ID 用控制台一行代码取出）。提示"Cookie 约 30 天过期，在网页上退出登录不会让它失效"。
   - 登录令牌（自动续期）（sub2api）：access_token、refresh_token 两个输入框，配可折叠的"怎么获取"（用一行代码遍历 localStorage 打印含 token 的键）和复制按钮。提示"nam 会自动续期，请不要在别处同时使用这对令牌"。
   - 探测发现站点开启了人机验证时，显示提示条"该站登录需要人机验证，账号密码无法使用，请用会话 Cookie"，并把默认凭证方式改为会话 Cookie；用户仍选账号密码时给黄色警告。
4. 连通性测试：逐项显示站点可达、凭证有效、令牌列表、分组倍率、公告的结果和耗时。可以重新测试；失败时可以返回修改。
5. 填写上游货币汇率（附换算示例）、标签、备注。勾选保存后是否立即同步令牌、分组倍率和余额。最后点"保存并同步令牌"。

### 3.3 上游详情抽屉（多个标签页）
- 概览：
  - 显示余额、折合人民币、渠道数/令牌数、7 天成本。
  - 最近同步失败时显示失败提示。
  - 可编辑名称、地址、类型、标签、备注、上游货币汇率（提示：修改后会影响该上游所有渠道的上游渠道售价）。
  - 凭证状态，带"更换凭证"和"测试连通性"按钮。会话 Cookie 显示"Cookie 约 N 天后过期"（≤3 天黄色、已过期红色）；sub2api 显示"凭证更新于 x 前"；同步错误含"已失效"时也显示"更换凭证"。
- 分组倍率：显示上游的分组名、分组倍率、使用该分组的渠道数、更新时间。有"立即同步倍率"按钮。
- 上游模型价格：
  - 同步上游的逐模型价格（输入、输出、缓存读、缓存写，或按次价），并换算到各分组。
  - 与渠道上游分组倍率偏差超过 5% 的模型会被标出，可以设为该模型的单独倍率。"推算倍率"按各渠道的上游价推算上游分组倍率。
- 令牌：
  - 列出令牌名、分组、额度、状态、模型数（点击展开模型列表）、是否已建渠道。
  - 未建渠道的令牌有"建渠道"按钮，点击后跳到渠道页的批量创建，并预选该上游。
  - 可以手动录入令牌；newapi/onehub 类上游还可以"在上游新建令牌"（弹窗填写令牌名、分组、额度）。
  - **令牌模型列表**：每个令牌可以记录本站要对外开放的模型（即对应 NewAPI 渠道的模型列表）。
    - 点击令牌行的模型数，展开模型编辑区：显示当前模型列表（可删除），有"从上游拉取"按钮和手动输入框。
    - "从上游拉取"：用该令牌的 key 调用上游 `/v1/models` 拿到模型列表，然后让人工勾选要加入的模型（厂商模板快速勾选）。底层复用 NewAPI 本体的 `POST /api/channel/fetch_models` 逻辑。
    - 未建渠道时"建渠道"按钮会把该令牌的模型列表带入批量创建向导的初始值。
- 公告：显示检测时间、是否有变化、内容摘要。
- 适配器配置：只有 generic 类型需要配置。
  - 字段有余额请求地址、请求方法、请求头、JSON 路径、换算系数、公告页面地址。
  - 有"测试"按钮，显示解析出的余额。
  - 其它类型只读展示。
- 同步日志：显示时间、任务、结果、耗时、说明。
- 底部按钮：
  - 删除上游：确认后，把该上游所有渠道的删除加入草稿。
  - 立即同步
  - 保存

## 4. 渠道（核心页）

### 4.1 页面结构
- 页头按钮：
  - 草稿计数、放弃草稿（需要确认）
  - 应用变更
  - 批量创建
- 工具栏：
  - **分组方式**：按厂商（默认）、按上游、按标签、不分组。
  - **筛选**：状态（启用、手动禁用、自动禁用）、上游、厂商、标签、同步状态（已同步、草稿、漂移、错误）。
  - **搜索**：按名称、令牌、模型搜索。
  - **模型选择**（可搜索，选项旁显示包含渠道数）：
    - 选中后，统计列与成本列<u>只计算该模型</u>（见 4.2）。
    - 记录在网址参数 `model` 里；清除后切回全部模型汇总。
  - **统计时长**：
    - 预设档位：最新（每渠道 24h 内最近 100 条日志，直查 NewAPI）、3 天、7 天；默认选"最新"。
    - 自定义：弹出小浮层，输入正整数并选单位（小时 / 天），范围 1 小时到 186 天。
    - 生效自定义值时，下拉框直接展示其文本（如"12 小时"）。
  - **批量操作**：有勾选行时显示"批量启用 / 批量禁用"。
  - **列设置**："列"按钮内勾选要显示的列。
- 主体双表结构（中间分隔条可拖动调整高度）：
  - **上表**：渠道表格。
  - **下表**：当前选中渠道的模型明细。
    - 顶部带"模型明细"标题栏，可点击折叠。
    - 折叠后上表占满全高，再展开恢复原高度比例。
    - <u>折叠状态记在浏览器本地</u>，不进布局保存。

### 4.2 渠道表格
- **分组与排序**：
  - 默认按厂商分组，且<u>全部展开</u>。
  - **组顺序规则**：
    - 按厂商分组：跟随设置页"厂商分组"的顺序，不可在此拖动。
    - 按上游 / 标签分组：可直接拖动组标题调序，顺序随布局保存。
    - 新出现的组按名称排在末尾，"未分组"固定在最后。
  - **组内默认排序**：优先级↓、权重↓、名称↑。
- **组标题行**：
  - 显示组名、渠道数、平均成功率、成本合计；点击可展开或折叠。
  - 选定模型时，组内不含该模型的渠道不计入统计。
- **表格列清单**（✎ 表示支持直接编辑）：
  - 勾选框
  - 状态
  - 名称 ✎：全站必须唯一。
  - 上游 ✎：
    - 下拉选择已有上游。
    - 切换上游时自动用渠道 key 匹配令牌（嵌入模式直接匹配；独立模式若需二次验证则提示手动选）。
    - 匹配不到时自动新建 manual 令牌记录。
  - 令牌 ✎：下拉选择该上游已有令牌（含 manual），支持留空。
  - 厂商 ✎：
    - 厂商**自动决定**渠道的 NewAPI 分组名。
    - 改厂商时分组自动跟随改动；渠道分组禁止手动单改。
  - 模型：
    - 单元格显示"x 个模型"，鼠标悬停显示完整列表。
    - 支持复制粘贴（格式为逗号分隔的模型名）。
    - 双击打开模型编辑器追加或移除模型。
    - 校验规则：一个模型名只能属于一个厂商分组，跨组报错。
  - 上游分组倍率 ✎：
    - 标注来源为自动或手动。
    - <u>选了模型时变为只读</u>，显示该模型的生效倍率（含模型级覆盖），且不显示来源标记。
  - 上游货币汇率（元/$）
  - 上游渠道售价（= 上游分组倍率 × 上游货币汇率 ÷ 美元参考汇率，原厂价的百分比）：选了模型时按该模型生效倍率计算。
  - 单次成本（元）：按标准请求（1000 输入含 200 缓存、500 输出）测算；没选模型用测试模型，选了模型用所选模型。
  - 余额：
    - 显示格式为“美元 ≈ 人民币”，所有行 `≈` 符号上下对齐。
    - 列宽放不下最宽行时，<u>所有行统一只显示人民币</u>；悬停看完整内容。
  - 优先级 ✎
  - 权重 ✎
  - 标签 ✎
  - 成功率
  - 首字延迟、吐字速度：<u>只有选了模型才显示</u>；没选时显示"—"，表头提示"选择模型后显示"。
  - 缓存命中率
  - 成本（原厂价百分比，按颜色梯度高亮）：
    - **实际负载成本**：渠道实际扣费 ÷ 同样请求不算缓存的原厂价费用；缓存命中越高数值越低。
    - **实际计费倍率**（默认隐藏）：实际扣费 ÷ 算缓存优惠的原厂价费用；正常约等于上游渠道售价，显著偏高说明上游多扣了。
    - **标准负载成本**（默认隐藏）：按同厂商近 7 天全量渠道平均 token 比例理论测算；可跨渠道横向比价，无流量渠道也能算。
  - 价格档 / 质量档评级（默认隐藏）：
    - 价格档：按同厂商内标准负载成本排名（便宜、中、贵）。
    - 质量档：按成功率 Wilson 下界评分（≥ 99% 好，≥ 95% 中，其余差）。
  - 成本（元，默认隐藏）
  - 同步状态：已同步、草稿、草稿·新建、草稿·删除、漂移（点击打开对比）、错误。
- **高亮与弱化提示**：
  - 选定模型后，不含该模型的渠道在统计列与成本列统一显示"—"。
  - 修改过的单元格、发生漂移的字段均高亮显示。
  - 被禁用的行整体使用弱化置灰样式。

### 4.3 表格交互（参考 oc-modal-configurator）
- 编辑：
  - 双击、Enter 或 F2 进入编辑；Enter 保存，Esc 取消。

### 4.5 批量创建向导（弹窗，5 步）
1. 选上游：显示类型、上游货币汇率、令牌数、已建渠道数。
2. 选令牌：可多选，有"全选未建渠道的"按钮。显示令牌的分组、分组倍率、上游渠道售价、额度、状态，以及是否已有渠道和已有几个模型。
3. 每个令牌独立选模型：
   - 令牌列表逐条展开，每个令牌单独显示自己的模型选择区；默认带出该令牌已保存的"本站模型列表"，可以在这里修改。
   - 有"从上游拉取"按钮（调用上游 `/v1/models` 后让人工勾选）和手动输入框；厂商模板快速勾选。
   - 一个令牌的模型通常只属于一个厂商，建一个渠道；若跨多个厂商，会显示提示，并在预览里按厂商拆分。
   - 缺价的模型会标出。
   - **厂商自动决定渠道的 NewAPI 分组**，不用手选；某个模型已属于其它厂商分组时给出提示。
4. 命名与默认值：
   - 命名规则 `nam-<上游>-<令牌>-<厂商>`。
   - 填写默认优先级、权重、标签（对所有令牌生效）。
   - 测试模型：默认自动选渠道内最便宜的模型，也可以手动指定（按令牌 / 按厂商分组）。
   - 说明上游分组倍率的来源：自动推算或手动填写（可按令牌覆盖）。
5. 预览：列出将生成的渠道，包括名称、令牌、厂商（及其分组）、模型、推算出的上游分组倍率、价格档 / 质量档评级（新渠道没有数据时留空）、优先级、权重、测试模型。重名的会被标出。点击"加入草稿"后跳到渠道页。

- 从上游详情的"建渠道"进入时，直接从第 2 步开始。

  - 采纳 NewAPI 值：只更新 nam。

## 5. 模型与价格

**核心思路**：NewAPI 里的模型价格保持 **原厂价**，nam 不自动改。nam 只给每个厂商定一个**售价**，写成该厂商分组的倍率。

- 厂商定价区（每个厂商一行）：
  - 定价模式有两种：**固定**（手填售价），或**跟随参考成本**（售价 = 参考成本 × 加价比例）。
  - 加价比例：只在跟随模式下填写。
  - 参考成本（原厂价的百分比）：该厂商启用渠道中优先级最高的一层，按权重加权平均上游渠道售价；悬停列出所用渠道、优先级和权重。
  - 售价（原厂价的百分比）：固定模式手填，跟随模式自动算出；旁边小字折合"≈ X.XX 元 / 原厂 $1"。
  - 厂商分组倍率：NewAPI 当前值 → 将写入的值（= 售价 × 美元参考汇率 ÷ 站点汇率，<u>四舍五入保留 3 位小数</u>）。固定模式下可以直接改倍率，售价按倍率反算；跟随模式下只读。
  - 近 7 天毛利率：（收入 − 成本）÷ 收入。<u>计算方式还不准确，暂不处理</u>（第 26 轮）。
  - 状态：已同步、待写入、待确认、漂移、无可用渠道、未设置。
    - 待确认：跟随模式下售价变化超过变化保护阈值，显示新值，主人点"确认"后写入。
    - 漂移：NewAPI 里的厂商分组倍率被手动改过。可"采纳 NewAPI 值"（转固定模式，只写 nam），或"以 nam 为准覆盖"（需确认）。
  - 编辑模式、加价比例、售价、倍率只写 nam，状态变成"待写入"，要经"预览写入"才写 NewAPI。
  - 第一次接管时，按 NewAPI 现有的分组倍率反算售价，不改价（倍率不是 3 位小数也判为已同步）。
- 页头按钮：
  - 同步价格库：LiteLLM，只同步站内存在的模型。只匹配<u>原厂</u>的价格：LiteLLM 里与模型名完全相同的条目；没有时，只接受原厂前缀（anthropic、openai、gemini、deepseek、xai、moonshot、zai、dashscope、minimax、mistral）加同名的条目；其它转售商的条目一律不用，模型显示"缺价"，可手动覆盖或设别名。
  - 立即计算：重新计算一遍；自动写入开着时会顺带写入跟随模式的厂商。
  - 预览写入：弹窗列出将要写入的内容，确认后写入。
- 筛选：
  - 状态：全部、正常、缺价、按次计费，各显示数量。
  - 厂商
  - 搜索：模型名或别名
- 排序：
  - 默认把未设价格的模型排在前面。
  - 搜索时，前缀命中排在中间命中前面；同一命中类型内再按"是否设价"排序，最后按名称排序。
- 模型表列（第 26 轮：去掉"偏差"，价格库价格和 NewAPI 当前价并排显示，由主人自己对照）：
  - 模型（厂商、别名）
  - 价格库价格：输入、输出、缓存读、缓存写，或按次价
  - 价格来源：价格库 / 手动覆盖
  - NewAPI 当前价格：NewAPI 里实际生效的模型价格，格式与价格库价格一致
  - 渠道数：使用该模型的渠道数
  - 状态：正常 / 缺价 / 按次计费
- 行操作：
  - 更多菜单：查看明细（抽屉，并排列出价格库价格和 NewAPI 当前价，以及使用该模型的渠道）、覆盖原厂价（弹窗，见下）、设置别名（弹窗，见下）。
  - 双击行打开明细。
  - "按建议执行"（手动把价格库价格写进 NewAPI 的模型价格，先预览再确认）放在 M5 第二批，改成勾选模型后批量写入。
- 覆盖原厂价（弹窗）：
  - 选择计费方式：按 token 或按次。
  - 填写各项价格和备注。
  - 有"清除覆盖"按钮。只写 nam。
- 设置别名（弹窗）：每行填一个上游模型名，映射到官方模型名。只写 nam。
- 预览写入（弹窗）：
  - 列出各厂商分组倍率的变化：旧售价 → 新售价、旧倍率 → 新倍率。
  - 列出跳过的厂商和原因（待确认、漂移、未设置、无可用渠道）。
  - 列出 NewAPI 选项（`GroupRatio`、`UserUsableGroups`、`AutoGroups`）写入前后的内容，可折叠。
    - `GroupRatio` 只改厂商分组的键，其它分组不动。
    - `UserUsableGroups` 补上厂商分组和 `auto`。
    - `AutoGroups` 厂商分组按设置页顺序排在前面，原有的其它分组接在后面。
  - 手动写模型价格时（第二批），另列出对应 option（ModelRatio、CompletionRatio、CacheRatio 等）的变化。
  - 流程：写入前校验，写入后读回核对，并记录历史，可以回滚。

## 10. 设置

左侧有分区目录，点击可跳到对应分区。标注"写 NewAPI"的项保存前需要确认。

- NewAPI 连接：
  - 嵌入模式：只读显示运行模式、NewAPI 版本、是否检测到补丁。
  - 独立模式：地址、root 访问令牌、用户 ID。"测试连接"会显示版本、是否检测到补丁，并校验该用户是 root（角色 100），不是 root 时提示错误。
- 高危操作（查看凭证明文、修改站点汇率）：嵌入模式下需要先通过 NewAPI 的二次验证（2FA 或 Passkey）。
- 站点汇率：
  - 显示当前值（元 / 1 美元站内额度，现为 7），可以输入新值，然后点"预览影响"。
  - 弹窗说明影响：**厂商分组倍率整体缩放，人民币价格不变，已有余额被重新估值**。
  - 同时改写 NewAPI 的 `Price` 和 `USDExchangeRate`；不触发变化保护。
  - 必须勾选"我已了解"，再经过二次确认才能写入。
- 厂商分组：
  - 表格列：厂商、分组名、包含模型、在 AutoGroups 里的顺序。可以增删厂商；拖动行左侧的手柄调整顺序，渠道页按厂商分组时的组顺序跟着变。
  - 保存时需要确认，然后写 NewAPI（`GroupRatio`、`AutoGroups`、`UserUsableGroups`）。
  - 校验：一个模型名只能属于一个厂商分组，否则 auto 会选到顺序靠前的分组、价格出错；渠道的分组必须正好是所属厂商的分组。
  - 提示：nam 不开启 NewAPI 的"默认使用 auto 分组"，用户需要自己选 `auto`；不用 auto 的令牌不受这套定价影响。
  - 用户分组加价：以后再做。
- 定价参数：
  - 美元参考汇率（元/$，默认 7.2，必须大于 0 且不超过 100）：用于把成本和售价换算成原厂价的百分比。保存后渠道和统计数据会刷新；各厂商分组倍率需要重新写入。
  - 变化保护阈值（默认 50%，作用于跟随模式下的售价变化）
  - 最小变动（默认 2%）：跟随模式下变化小于它时，自动写入跳过。
  - 自动写入开关（默认关闭）：打开后定价任务（每 1 小时）自动写入跟随模式的厂商；固定模式一律手动写入。
- 调度间隔：每个后台任务的执行间隔，单位可选分钟、小时、天。
- 日志保留：
  - NewAPI 原始日志保留天数：由 nam 负责清理，会写 NewAPI。
  - nam 聚合数据保留天数。
- NewAPI 自动禁用/恢复：
  - 自动禁用开关、自动恢复开关、全量定时测试开关（建议保持关闭）、测试间隔。
  - 修改开关需要确认，然后写 NewAPI。
- 备份：立即备份、最近备份列表、下载。
- 修改管理员密码（只在独立模式出现）：输入当前密码、新密码和确认密码。修改后，其它会话全部失效。
